# Dr. Shannon Francesca Fernandes

Personal website for **Dr. Shannon Francesca Fernandes** — Consultant Obstetrician &amp; Gynaecologist at Father Muller Hospital, Kankanady, Mangalore.

A single-page site (`index.html`) featuring scroll-reveal animations, animated counters, an education timeline, an embedded Instagram reel, and a WhatsApp-based appointment booking flow. Built with Tailwind CSS (CDN), Playfair Display + DM Sans, and Material Symbols.

**Live site:** https://lumestudiosweb-stack.github.io/dr-shannon-fernandes/

## Editing
- All content and styling live in `index.html`.
- The portrait image is `2022-09-20.webp`.
- WhatsApp booking number is set via the `CLINIC_WHATSAPP` constant near the top of the page script.
